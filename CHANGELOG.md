# Changelog

## 1.3.0

- Adds bulk style changes for tag-styled note types, across all notes or notes appearing in a selected deck.

## 1.2.0

- Shows the decks containing notes of the selected managed note type.

## 1.1.0

- Replaced the White palette with Inverted. The question header is black in light mode and white in dark mode.
- Enabled Base, Filled, and Outlined finishes for Inverted.
- Migrates the saved White appearance on managed note types to Inverted when their styles are updated.
